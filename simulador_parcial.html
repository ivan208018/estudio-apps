0 · Fundamentos de programación (si ahí te falló el parcial)

Programar = dar instrucciones en orden a la computadora.

  • val = no cambia (inmutable). var = sí cambia.
  • Tipos: Int (entero), Double (decimal), String (texto), Boolean (true/false), Char (1 carácter).
  • 10 / 3 = 3 (división entera corta decimal) · 10.0 / 3 = 3.33
  • 10 % 3 = 1 (módulo = resto de la división)
  • = asigna · == compara → if (x = 5) es error.
  • Lógicos: && (y), || (o), ! (no).
  • if puede devolver valor: val r = if (c) "sí" else "no".
  • Ciclos: for (i in 1..5) incluye el 5 · until excluye · downTo baja · step salta.
  • Función: fun nombre(p: Tipo): Tipo { return ... }; sin retorno = Unit.
  • Plantillas: "Hola $nombre" y "Suma ${a + b}".
Ejemplo resuelto: 
var total = 0
for (i in 1..5) { if (i % 2 == 0) total += i }
println(total)   // pares: 2 + 4 = 6
1 · Unidad 1 — Kotlin + Android Studio + primeros componibles
  • Android Studio = IDE; AVD Manager = emulador; Logcat = consola; Gradle = compilación (build.gradle).
  • MainActivity es la pantalla de entrada; se declara en AndroidManifest.xml.
  • Compose es declarativo: describes qué mostrar, no cómo construirlo. Todo es Kotlin (sin XML).
  • Todo componible: anotación @Composable + nombre en PascalCase + no devuelve valores.
  • Text(text = ...) · Image(painter = painterResource(R.drawable.x), contentDescription = ...)
  • contentDescription = accesibilidad (obligatorio; null solo si es decorativa).
  • Modifier.padding(16.dp) · .fillMaxWidth() · .size() — el orden importa.
  • Column (vertical), Row (horizontal), Box (capas).
  • Recomposición = redibujo automático cuando cambia el estado.
  • @Preview = ver la UI sin ejecutar la app. La app se envuelve en MaterialTheme.
2 · Unidad 2 — when, nulabilidad, clases, lambdas y ESTADO

when (como switch, sin break); si es expresión necesita else; acepta in 1..5 e is Tipo.

Nulabilidad — tabla clave:

SignoNombreQué hace
String?nullableel tipo admite null
a?.lengthsafe callsi es null → null; si no → ejecuta
a ?: "x"Elvissi es null → valor por defecto
a!!assertionasume que no es null (¡explota si lo es!)

Clases: class Persona(val nombre: String, var edad: Int) — la clase es el plano, el objeto es la instancia. Métodos dentro de llaves; this = objeto actual.

Lambdas y tipos de función: 

val doble: (Int) -> Int = { it * 2 }
listOf(1,2,3).filter { it > 1 }   // it = parámetro implícito
// última expresión = valor de retorno

ESTADO (lo más importante): 

var count by remember { mutableStateOf(0) }   // ✅ la UI se actualiza
var count = 0                                 // ❌ nunca se redibuja

  • remember conserva el valor entre recomposiciones.
  • State hoisting: el estado vive en el padre y baja por parámetros.
  • Pruebas: assertEquals(valorEsperado, valorObtenido) — el orden importa.

4 · Unidad 4 — Ciclo de vida, ViewModel, StateFlow, Navigation

Ciclo de vida: onCreate → onStart → onResume → (en uso) → onPause → onStop → onDestroy.

  • onCreate = inicializar la UI (setContent).
  • Al rotar, la Activity se destruye y recrea → las variables normales se pierden.
  • ViewModel = guarda el estado y sobrevive a la rotación.

Arquitectura por capas: UI (Composables + ViewModel) · Dominio (use cases) · Datos (repositorios).

UDF (flujo unidireccional): estado ↓ de ViewModel a UI · eventos ↑ de UI a ViewModel.

Patrón ViewModel completo: 

class Vm : ViewModel() {
    private val _uiState = MutableStateFlow(Estado())          // privado
    val uiState: StateFlow<Estado> = _uiState.asStateFlow()    // público

    fun accion() {
        _uiState.value = _uiState.value.copy(campo = 1)  // actualizar
    }
}

// En la UI:
val state by viewModel.uiState.collectAsState()  // ← conectar con Compose

Navigation: 

val nav = rememberNavController()
NavHost(nav, startDestination = "inicio") {
    composable("inicio")      { Inicio(onIr = { nav.navigate("detalle") }) }
    composable("detalle")     { Detalle(onVolver = { nav.popBackStack() }) }
    composable("pedido/{id}") { /* backStackEntry.arguments */ }
}

  • navigate = apila (avanza) · popBackStack = desapila (atrás).
  • Argumentos: {ruta} obligatorio, ?clave= query; tipos con navArgument.
  • Ventana: Compact <600 dp (teléfono) · Medium ≥600 · Expanded ≥840 → panel lateral.
